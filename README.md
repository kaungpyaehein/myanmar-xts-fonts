# Myanmar XTS Fonts

Myanmar (Burmese) fonts for **Xteink e-readers on the original (stock) firmware**.

**[⬇ Download the latest release](../../releases/latest)**

## Fonts

- Pyidaungsu XTS
- Pdk XTS (based on Padauk)
- Noto Sans Myanmar XTS
- Noto Serif Myanmar XTS
- Myanmar Latpan XTS

## Install

1. Connect the Xteink's SD card to your computer.
2. Copy the `.ttf` files into the **`Pushed Fonts`** folder.
3. Copy `XTS-Test-Book.epub` into **`Pushed Books`**.
4. On the device, open the test book and choose an **… XTS** font in font settings.

> These fonts work only with **XTS-converted books**. Normal Myanmar epubs won't display
> correctly with them.

## မြန်မာ

Xteink **မူလ firmware (stock)** အတွက် မြန်မာဖောင့်များ ဖြစ်ပါသည်။

1. `.ttf` ဖိုင်များကို SD ကတ်ရှိ **`Pushed Fonts`** ထဲ ကူးပါ။
2. `XTS-Test-Book.epub` ကို **`Pushed Books`** ထဲ ကူးပါ။
3. စက်ပေါ်တွင် စာအုပ်ဖွင့်ပြီး ဖောင့်ကို **… XTS** ဟု ရွေးပါ။

> ဤဖောင့်များသည် **XTS ပြောင်းထားသော စာအုပ်များ**နှင့်သာ အလုပ်လုပ်ပါသည်။
